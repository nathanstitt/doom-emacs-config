# Doom Emacs Config

My personal [Doom Emacs](https://github.com/doomemacs/doomemacs) configuration.

## Structure

- `init.el` — Doom module selection
- `config.el` — Main configuration, loads modular files from `nas/`
- `packages.el` — Additional packages
- `nas/` — Modular config files (LSP, JS/TS, keybindings, etc.)
